🍽️ Tablekeeper

Restaurant reservations that cannot double-book

1. Set up

A booking belongs to a restaurant and a table, so create those first.

2. Book

The service publishes no availability endpoint, so the booking attempt is also the availability check: the server refuses it with SLOT_TAKEN when the table is gone.

3. Confirm

Read back from the server after every change, so what is shown is what was stored.
